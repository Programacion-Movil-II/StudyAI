# StudyAI

StudyAI es una aplicación móvil desarrollada en **Android Studio con Java**, que permite realizar preguntas a la inteligencia artificial mediante la API de Gemini.

##  Tecnologías utilizadas

- **Java** — Lógica de la aplicación.
- **Android Studio** — Entorno de desarrollo.
- **XML** — Diseño de la interfaz.
- **Retrofit** — Consumo de la API REST.
- **Gson** — Manejo de datos JSON.
- **Gemini API** — Generación de respuestas.

## Configuración

1. Clonar el repositorio y abrirlo en Android Studio.
2. Obtener una API Key desde [Google AI Studio](https://aistudio.google.com/apikey).
3. Agregar la siguiente línea en `local.properties`:

   ```properties
   GEMINI_API_KEY=TU_API_KEY
   ```
